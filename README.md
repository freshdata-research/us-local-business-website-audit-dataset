## Key Findings (Batch #1 — Austin, Dallas, Houston, San Antonio)
Out of **940** local service businesses audited across 6 core categories (Dentists, Plumbers, Roofers, HVAC, Auto Repair, Attorneys), **148 businesses (15.7%)** exhibited verified website defects after stripping HTTP `401/403/406/429/503` firewall false positives:
- **San Antonio, TX:** 21.2% defect rate ([Dataset](https://freshdata.today/datasets/san-antonio-tx/))
- **Dallas, TX:** 16.5% defect rate ([Dataset](https://freshdata.today/datasets/dallas-tx/))
- **Houston, TX:** 15.5% defect rate ([Dataset](https://freshdata.today/datasets/houston-tx/))
- **Austin, TX:** 9.7% defect rate ([Dataset](https://freshdata.today/datasets/austin-tx/))
